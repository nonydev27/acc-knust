# ACC KNUST Session Countdown Widget

An interactive session countdown widget built for the Amalitech Coding Club (ACC) KNUST Frontend Track.

## Features
- Live countdown timer showing days, hours, minutes, and seconds until the next session.
- Interactive session switcher between **Git & Frontend Clinic** and **UI/UX & Dev Jam**.
- Glassmorphic centered card layout using HTML, CSS, and vanilla JavaScript.

## How to Run or View
1. Open `frontend/widgets/karlll-d/index.html` directly in a web browser, or serve the repository folder using a local development server (such as VS Code Live Server).
