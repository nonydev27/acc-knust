# ACC KNUST Event Countdown Widget

## Overview
The ACC KNUST Event Countdown Widget is a responsive web application that displays the time remaining until a scheduled coding club event.

## Features
- Displays the remaining days, hours, minutes, and seconds.
- Updates the countdown every second.
- Displays a message when the event time is reached or has passed.
- Uses a responsive layout for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download the repository.
2. Navigate to `frontend/widgets/j-agyeiwaa/`.
3. Open `index.html` in a web browser.
4. The countdown starts automatically.

No additional libraries or installations are required.

## Customization
To change the event date and time, edit the `eventDate` variable in `script.js`.

The current date, December 5, 2026, at 10:00 AM, is a demonstration date and is not a confirmed official meeting date. The countdown uses the browser's local time.
