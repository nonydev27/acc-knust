# ACC KNUST Event Countdown Widget

## Overview
The ACC KNUST Event Countdown Widget is a responsive web application that displays the time remaining until an upcoming coding club event.

## Features
- Displays the remaining days, hours, minutes, and seconds.
- Updates the countdown every second.
- Displays a message when the countdown reaches the event time.
- Uses a responsive layout for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository.
2. Navigate to `frontend/widgets/j-agyeiwaa/`.
3. Open `index.html` in a web browser.
4. The countdown will begin automatically.

No additional libraries or installations are required.

## Customization
To change the event date and time, edit the `eventDate` variable in `script.js`.
