# ACC KNUST Event Countdown & Schedule Widget

Interactive widget by **Daniel Sakyiamah Yirenkyi (`@ydksakyi`)** for switching upcoming ACC KNUST frontend sessions, viewing a live countdown, and toggling between light and dark modes.

## How to View / Run

1. Open `frontend/widgets/ydksakyi/index.html` directly in any web browser, or serve the repository root using a local static server (such as the VS Code Live Server extension).
2. Click the session tabs to switch events and use the **Dark Mode / Light Mode** button in the top-right corner to toggle themes.
