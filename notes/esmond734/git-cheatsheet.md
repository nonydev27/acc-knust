
 Git Cheatsheet

## 1. git clone

function: Downloads an existing Git repository from GitHub to your local computer.


## 2. git status

**Purpose:** Shows the current state of your working directory and staged changes.


## 3. git add

**Purpose:** Adds modified or new files to the staging area before committing.


## 4. git commit

**Purpose:** Records staged changes in the Git repository with a descriptive message.

```bash
git commit -m "Add new feature"
```

## 5. git push

**Purpose:** Uploads local commits to a remote repository such as GitHub.

```bash
git push origin main
```

## 6. git branch

**Purpose:** Displays all local branches in a Git repository. It can also be used to create and manage branches.

```bash
git branch
```

## 7. git status

**Purpose:** Shows the current state of the working directory, including modified, staged and untracked files.

```bash
git status
```
