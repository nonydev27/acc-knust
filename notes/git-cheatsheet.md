### **Git Cheatsheet**

##### Author: Amoah Margaret Serwaa



#### 1\. git clone

###### Purpose: Copies a repository from GitHub to your computer.

###### git clone <repository-url>

###### 

#### 2\. git status

###### Purpose: Shows the current state of your repository.

###### git status

###### 

#### 3\. git add

###### Purpose: Stages files before committing.

###### git add .



#### 4\. git commit

###### Purpose: Saves changes as a commit.

###### git commit -m "message"



#### 5\. git push

###### Purpose: Uploads commits to GitHub.

###### git push origin branch-name


6. git diff
Purpose: Shows the differences between file versions and changes.

git diff
